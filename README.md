# REVSTORE

Website top up game online (demo frontend) berbasis HTML, CSS, dan JavaScript.

## Fitur
- Daftar game dan pencarian
- Top up dengan pilihan nominal dan metode pembayaran
- Kode pesanan otomatis dan cek transaksi
- Login, register, dan riwayat pembelian
- Dashboard admin (produk, transaksi, pengguna, banner, cover)

## Demo
https://revieabdilian01-cyber.github.io/revstore/

## Catatan
Versi demo: data disimpan di browser (localStorage) dan pembayaran masih simulasi.
Gambar cover hanya digunakan untuk keperluan tugas kuliah (non-komersial).
